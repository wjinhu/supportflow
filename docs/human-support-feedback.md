# 人工会话超时与服务评价

人工会话在双方连续五分钟没有成功发送新消息后自动结束，等待接待和正在接待的会话均适用。没有消息时从创建会话起算；客服接待、刷新、读取历史、输入草稿和重复发送同一消息标识均不延长计时。每条新买家消息或客服消息提交成功后，重新起算五分钟。

时间来自MySQL UTC时钟。后台每五秒扫描一批过期会话，浏览器沿用四秒轮询，页面关闭也不会阻止服务端结束。扫描任务与发送、接待操作采用一致的范围、会话锁顺序；关闭前重新检查最新消息时间。已到截止时间的发送操作也会提交超时关闭，再拒绝新消息；旧消息响应丢失后的同内容重试仍可取回原记录，但不重新开始计时。

结束原因区分买家主动结束、客服主动结束、无消息超时，以及旧版本历史结束。聊天记录继续保留，人工占用状态解除，可重新联系人工或继续智能咨询。

新会话结束后，买家端弹出“客服评价”：必选1至5星，可选填最多500字纯文本意见，也可暂不评价。未接通客服的会话说明为等待体验。暂不评价不会自动提交；当前页面不会对同一会话反复弹窗，也可以通过“评价本次服务”再次打开。未评价的超时会话在重新打开页面后仍可提示；已提交的评价恢复后显示星级，不再弹出。

只有该会话所属买家可以提交评价，且必须已结束。同一会话只保存一份评价；相同内容重试返回原结果，不同内容再次提交会被拒绝。后台校验店铺、会话归属、评分、长度和纯文本，客服不能替买家评价。评价与结束原因保存在原会话记录，消息表保持不可改写。

V23只向已有人工会话表增加字段和索引，按真实历史消息时间回填活动时间；不会补造消息或评价。沿用原表权限，无需额外授权脚本。旧应用关闭会话时未填写结束原因仍兼容，旧前端缺少新字段时仍可读取历史。
